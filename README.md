# MeTOMe — деплой в облако (Railway + GitHub)

Это папка для публикации мессенджера в интернете, чтобы он работал,
даже когда твой компьютер выключен.

Файлы:
- `server.py` — сервер (в облачном режиме `CLOUD=1`, HTTP+WebSocket на одном порту)
- `client.html` — клиент (подключается к WebSocket на том же порту через `/ws`)
- `notification.mp3` — звук уведомлений
- `Dockerfile`, `requirements.txt`, `.dockerignore` — конфиг для Railway

## Как опубликовать (9 шагов)

### Шаг 1. Загрузи папку в GitHub
1. Открой github.com и войди в свой аккаунт.
2. Нажми зелёную кнопку **New repository** (в левом верхнем меню или на главной).
3. Назови, например, `metome`. Выбери **Public** (бесплатно, для Railway подходит).
4. Нажми **Create repository**.

### Шаг 2. Залей файлы из этой папки в репозиторий
Зайди в созданный репозиторий → кнопка **Add file** → **Upload files**.
Перетащи сюда файлы: `Dockerfile`, `server.py`, `client.html`,
`notification.mp3`, `requirements.txt`, `.dockerignore`.
Нажми **Commit changes**.

### Шаг 3. Зарегистрируйся на Railway
1. Открой **https://railway.app**.
2. Нажми **Continue with GitHub** и войди через свой GitHub-аккаунт.
3. Railway попросит разрешение на доступ к репозиториям — разреши.

### Шаг 4. Создай проект из своего репозитория
1. Нажми **New Project**.
2. Выбери **Deploy from GitHub repo**.
3. Выбери репозиторий `metome`.
4. Railway сам увидит Dockerfile, соберёт и запустит сервер.

### Шаг 5. Дождись сборки
Несколько минут будет статус **Deploying**, затем **Healthy / Running**.

### Шаг 6. Получи свой публичный адрес
1. В проекте нажми на сервис → вкладка **Settings**.
2. Найди **Networking** → кнопка **Generate Domain**.
3. Railway даст адрес вида: `https://metome-production.up.railway.app`
   — это и есть твоя ссылка для друзей.

### Шаг 7. Проверь
Открой полученную ссылку в браузере телефона (не на компе).
Должен открыться MeTOMe. Зарегистрируйся — данные сохранятся в облаке.

### Шаг 8. Дай ссылку друзьям
Все друзья открывают твою ссылку на телефоне/компе — из любой сети,
даже когда твой ПК выключен. Всё работает круглосуточно.

### Шаг 9. Будущие обновления
Когда захочешь изменить приложение: правь `server.py`/`client.html`
локально, залей в GitHub (Commit), и Railway **сам пересоберёт** сервер.

## Важно
- Данные пользователей (аккаунты, чаты, файлы) будут храниться в облаке Railway.
- На бесплатном слое сервер может «засыпать» при долгом бездействии —
  тогда просто открой ссылку (она его «разбудит»).
- У тебя может быть запрошена карта для верификации на Railway.
